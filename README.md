# AMS Project Documentation

Technical documentation for three ServiceNow automation workstreams: the Care
Agent Onboarding Portal, CATS (Customer Appeals Tracking System), and Delivery
Delay Automation.

**[View the complete project documentation](https://praneeth-97-pv.github.io/AMS_Project-/)**
| [Open the HTML source](./index.html)



## Project workstreams

- **Care Agent Onboarding Portal** — automates agent account creation,
  validation, approvals, and access provisioning.
- **CATS — Customer Appeals Tracking System** — documents case management,
  agent workspace, integration, migration, and AI-assisted workflow designs.
- **Delivery Delay Automation** — documents delivery-delay workflows,
  integrations, monitoring, and AI-agent orchestration.

## Technical overview

The project documentation covers ServiceNow modules and capabilities including
ITSM, ITOM, CSM, scoped applications, Agent Workspace, Flow Designer,
IntegrationHub, AI Agents, Virtual Agent, Knowledge Management, SecOps / SIR,
and Automated Test Framework (ATF).

Documented technologies and practices include JavaScript, GlideRecord, Script
Includes, Business Rules, UI Actions, UI Builder, React.js, HTML, REST/SOAP
APIs, OAuth 2.0, MID Server, ACLs, role-based access control, CI/CD, and
integration and regression testing.
